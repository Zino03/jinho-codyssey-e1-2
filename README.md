# 진호의 퀴즈 게임

Python으로 만든 **터미널 퀴즈 게임**입니다. 퀴즈를 풀고, 직접 추가하고, 최고 점수를 기록할 수 있으며, 프로그램을 종료했다가 다시 실행해도 퀴즈와 최고 점수가 유지됩니다.

## 1. 프로젝트 개요

| 항목 | 내용 |
|---|---|
| 종류 | Python 콘솔 프로그램 |
| 기능 | 퀴즈 풀기, 퀴즈 추가, 퀴즈 목록, 점수 확인, 종료 |
| 구조 | `Quiz`(퀴즈 한 문제)와 `QuizGame`(게임 전체 관리) 두 클래스로 역할 분리 |
| 저장 | 프로젝트 루트의 `state.json`에 UTF-8로 저장 (퀴즈 목록, 최고 점수) |
| 라이브러리 | 외부 라이브러리 없이 표준 라이브러리(`json`, `pathlib`)만 사용 |

프로그램을 만들며 아래를 직접 연습하는 것이 목표였습니다.

- 입력/출력 흐름과 조건문, 반복문, 함수
- 클래스(`__init__`, `self`, 속성, 메서드)로 코드를 역할별로 구조화
- JSON 파일 저장으로 데이터 영속성 구현, `try/except`로 오류 처리
- Git으로 변경 이력 관리 (커밋, 브랜치, 병합, clone, pull)

## 4. 실행 방법

필요 환경은 Python 3.12.3입니다. 외부 라이브러리를 설치할 필요는 없습니다.

```bash
git clone https://github.com/Zino03/jinho-codyssey-e1-2.git
cd jinho-codyssey-e1-2
python3 main.py
```

- 처음 실행하면 기본 퀴즈 6개로 시작하고, `state.json`이 자동으로 만들어집니다.
- Windows(WSL 없이)에서는 `python main.py`로 실행할 수 있습니다.
- 종료는 메뉴에서 `5`를 선택하거나 `Ctrl+C`를 누르면 됩니다. 어느 쪽이든 저장 후 종료합니다.

## 6. 기능 목록

| 메뉴 | 기능 | 설명 |
|---|---|---|
| 1 | 퀴즈 풀기 | 저장된 퀴즈를 차례로 출제합니다. 정답/오답을 알려주고, 오답이면 정답 번호도 보여줍니다. 모두 풀면 맞힌 개수와 점수를 표시하고, 최고 점수보다 높으면 갱신합니다. 퀴즈가 없으면 안내합니다 |
| 2 | 퀴즈 추가 | 문제, 선택지 4개, 정답 번호(1~4)를 입력받아 등록하고 바로 저장합니다 |
| 3 | 퀴즈 목록 | 등록된 퀴즈의 번호와 문제를 표시합니다. 퀴즈가 없으면 안내합니다 |
| 4 | 점수 확인 | 최고 점수를 표시합니다. 아직 퀴즈를 풀지 않았으면 안내합니다 |
| 5 | 종료 | 저장 후 종료합니다 |

점수는 `맞힌 개수 / 전체 문제 수 * 100`을 반올림한 정수입니다(예: 6문제 중 1문제 정답이면 17점).

### 입력/예외 처리

숫자 입력이 필요한 곳(메뉴 선택, 정답 입력, 정답 번호 입력)은 모두 같은 함수(`read`)를 사용해 아래를 처리합니다.

| 상황 | 예시 | 처리 |
|---|---|---|
| 앞뒤 공백 | ` 1 ` | 공백을 제거한 뒤 처리 |
| 숫자가 아님 | `abc` | 안내 메시지 후 **같은 질문으로 돌아가 재입력** |
| 허용 범위 밖 | `9`, `0` | 안내 메시지(`1 ~ 5 사이의 숫자를 입력해주세요.`) 후 재입력 |
| 빈 입력 | Enter만 입력 | 안내 메시지 후 재입력 |
| `Ctrl+C`, `Ctrl+D` | `KeyboardInterrupt`, `EOFError` | 비정상 종료 없이 안내 후 저장하고 종료 |
| 문제/선택지 입력이 빈 문자열이나 공백뿐 | 퀴즈 추가 시 | 안내 후 같은 항목에서 재입력 |
| `state.json`이 없음 | 첫 실행 | 기본 퀴즈로 시작하고 파일을 새로 만듦 |
| `state.json`이 손상됨 | 문법 오류, 키 없음, 값 이상 | 안내 메시지 후 기본 퀴즈로 초기화 |
| 파일 읽기/쓰기 오류 | 권한 문제 등 | 안내 메시지만 출력하고 프로그램은 계속 실행 |

## 7. 기본 퀴즈 목록

처음 실행할 때 사용하는 Python 기초 퀴즈 6개입니다.

| # | 문제 | 선택지 | 정답 |
|---|---|---|---|
| 1 | 키(key)와 값(value)의 쌍으로 데이터를 저장하는 자료형은? | list / dict / tuple / set | 2 (dict) |
| 2 | 다음 중 문자열(str) 값은? | 3 / 3.0 / True / "3" | 4 ("3") |
| 3 | 조건식이 참인 동안 계속 반복하는 반복문은? | while / for / if / def | 1 (while) |
| 4 | 함수가 계산한 결과를 호출한 곳으로 돌려줄 때 사용하는 키워드는? | print / input / return / break | 3 (return) |
| 5 | 클래스로 객체를 만들 때 자동으로 실행되어 초기값을 저장하는 메서드는? | `__str__` / `__del__` / `__call__` / `__init__` | 4 (`__init__`) |
| 6 | 오류가 발생해도 프로그램이 비정상 종료되지 않도록 처리할 때 사용하는 구문은? | if / else, try / except, for / while, import / from | 2 (try / except) |

기본 퀴즈는 `QuizGame.default_quizzes()`에서 `Quiz` 객체로 만들어집니다. 사용자가 추가한 퀴즈는 `state.json`에 저장되어 다음 실행에도 유지됩니다.

## 8. 파일 구조

```
.
├── main.py          프로그램 시작점 (QuizGame을 만들어 실행, Ctrl+C/EOF 처리)
├── quiz_game.py     QuizGame 클래스 (메뉴, 퀴즈 풀기/추가/목록/점수, 저장/불러오기)
├── quiz.py          Quiz 클래스 (퀴즈 한 문제, 출력, 정답 확인, dict 변환/복원)
├── state.json       저장 데이터 (퀴즈 목록, 최고 점수)
├── .gitignore       Git이 추적하지 않을 파일 (__pycache__ 등)
└── README.md        이 문서
```

| 파일 | 역할 |
|---|---|
| `main.py` | `QuizGame` 객체를 만들고 `run()`으로 시작합니다. `Ctrl+C`, `Ctrl+D`가 오면 안내 후 `save_state()`를 호출해 저장하고 종료합니다 |
| `quiz.py` | 퀴즈 데이터와 그 데이터를 다루는 기능만 담당합니다. 게임 흐름이나 파일 입출력은 모릅니다 |
| `quiz_game.py` | 게임의 흐름(메뉴, 풀이, 추가, 점수)과 파일 저장/불러오기를 담당합니다. 숫자 입력 함수 `read`도 여기에 있습니다 |

## 9. 클래스 설계

### Quiz (`quiz.py`)

퀴즈 한 문제를 표현합니다.

| 구분 | 이름 | 설명 |
|---|---|---|
| 속성 | `question` | 문제 문장 (문자열) |
| 속성 | `choices` | 선택지 4개 (리스트) |
| 속성 | `answer` | 정답 번호 1~4 (정수) |
| 메서드 | `show_quiz()` | 문제와 번호가 붙은 선택지를 출력 |
| 메서드 | `check(user_choice)` | 사용자가 고른 번호가 정답이면 `True`, 아니면 `False` 반환 |
| 메서드 | `to_dict()` | JSON 저장을 위해 객체를 dict로 변환 |
| 클래스 메서드 | `from_dict(data)` | dict를 `Quiz` 객체로 복원. 키가 없거나 값이 올바르지 않으면 `KeyError`/`ValueError` 발생 |

`from_dict`는 아래를 검사해서 하나라도 어긋나면 예외를 일으킵니다. 이 예외를 `QuizGame.load_state()`가 잡아서 손상된 파일로 처리합니다.

- `question`이 비어 있지 않은 문자열인가
- `choices`가 문자열 4개로 이루어진 리스트인가
- `answer`가 1~4 사이의 정수인가 (`True`/`False`는 제외)

### QuizGame (`quiz_game.py`)

게임 전체를 관리합니다.

| 구분 | 이름 | 설명 |
|---|---|---|
| 속성 | `quizzes` | `Quiz` 객체의 리스트 |
| 속성 | `best_score` | 최고 점수 (정수). `-1`은 아직 풀지 않았다는 뜻 |
| 메서드 | `default_quizzes()` | 기본 퀴즈 6개를 만들어 반환 |
| 메서드 | `show_menu()` | 메뉴 출력 |
| 메서드 | `play_quiz()` | 퀴즈 풀이. 점수를 계산해 반환 (퀴즈가 없으면 `None`) |
| 메서드 | `add_quiz()` | 퀴즈 추가 입력과 등록, 저장 |
| 메서드 | `list_quizzes()` | 퀴즈 목록 출력 |
| 메서드 | `show_score()` | 최고 점수 출력 |
| 메서드 | `update_score(score)` | 새 점수와 최고 점수를 비교해 갱신 |
| 메서드 | `save_state()` | `quizzes`와 `best_score`를 `state.json`에 저장 |
| 메서드 | `load_state()` | `state.json`을 읽어 복원. 파일이 없거나 손상되면 기본 데이터 사용 |
| 메서드 | `run()` | 메뉴를 반복해서 보여주고 선택에 맞는 메서드를 호출 |

모듈 함수 `read(prompt, low, high)`는 `low~high` 범위의 정수가 입력될 때까지 반복해서 묻고, 그 정수를 반환합니다. 게임 상태가 필요 없어서 클래스 밖에 두었습니다.

### 프로그램 흐름

```
python3 main.py
  └ QuizGame()                       __init__
      ├ 기본 퀴즈 6개로 채움
      └ load_state()
          ├ 파일 없음   → 기본 데이터 유지 + state.json 생성
          ├ 파일 손상   → 안내 + 기본 데이터로 초기화
          └ 파일 정상   → 퀴즈, 최고 점수를 파일 내용으로 교체
  └ run()                            메뉴 반복
      ├ 1 퀴즈 풀기   → 점수 계산 → 최고 점수 갱신 → save_state()
      ├ 2 퀴즈 추가   → 입력 검증 → quizzes에 추가 → save_state()
      ├ 3 퀴즈 목록
      ├ 4 점수 확인
      └ 5 종료        → save_state() → 종료
  Ctrl+C / Ctrl+D     → 안내 → save_state() → 종료
```

## 10. 데이터 파일 설명 (state.json)

| 항목 | 내용 |
|---|---|
| 경로 | 프로젝트 루트 (`quiz_game.py`와 같은 폴더). `Path(__file__).parent / "state.json"`으로 지정해서 어디서 실행해도 같은 위치 |
| 인코딩 | UTF-8 (`ensure_ascii=False`로 한글이 그대로 저장됨) |
| 역할 | 퀴즈 목록과 최고 점수를 저장해 프로그램을 다시 실행해도 유지 |

### 스키마

```json
{
    "quizzes": [
        {
            "question": "키(key)와 값(value)의 쌍으로 데이터를 저장하는 자료형은?",
            "choices": ["list", "dict", "tuple", "set"],
            "answer": 2
        }
    ],
    "best_score": 100
}
```

| 필드 | 타입 | 설명 |
|---|---|---|
| `quizzes` | 리스트 | 퀴즈 목록 (비어 있어도 됨) |
| `quizzes[].question` | 문자열 | 문제 문장. 비어 있으면 안 됨 |
| `quizzes[].choices` | 문자열 4개의 리스트 | 선택지. 각각 비어 있으면 안 됨 |
| `quizzes[].answer` | 정수 (1~4) | 정답 번호 |
| `best_score` | 정수 (-1~100) | 최고 점수. **`-1`은 아직 퀴즈를 풀지 않았다는 뜻** (점수 0과 구분하기 위함) |

이 스키마를 벗어나는 파일은 손상된 것으로 봅니다.

## 11. 저장/불러오기 동작

### 저장 시점

| 시점 | 이유 |
|---|---|
| 퀴즈를 추가한 직후 | 프로그램이 갑자기 꺼져도 추가한 퀴즈 유지 |
| 퀴즈를 푼 직후 | 최고 점수 유지 |
| 종료(메뉴 5) 직전 | 마지막 안전장치 |
| `Ctrl+C`, `Ctrl+D` 처리 시 | 중단되더라도 가능한 범위에서 저장 |

### 불러오기 시 오류 처리

| 상황 | 발생하는 예외 | 처리 |
|---|---|---|
| 파일 없음 (첫 실행) | `FileNotFoundError` | 기본 데이터 유지, 파일을 새로 생성 (안내 없음) |
| JSON 문법 오류 | `json.JSONDecodeError` | 손상 안내 후 기본 데이터로 초기화 |
| 키 없음, 타입이나 값이 올바르지 않음 | `KeyError`, `TypeError`, `ValueError` | 손상 안내 후 기본 데이터로 초기화 |
| 읽기 권한 등 파일 접근 오류 | `OSError` | 안내 후 기본 데이터로 시작 (파일은 건드리지 않음) |

- `try` 안에서는 지역 변수에만 읽어 오고, **모두 검증을 통과했을 때만** `self.quizzes`, `self.best_score`에 반영합니다. 중간에 실패해도 데이터가 반쯤 바뀐 상태로 남지 않습니다.
- 더 구체적인 예외(`FileNotFoundError`)를 `OSError`보다 먼저 써야 합니다. `FileNotFoundError`가 `OSError`의 하위 예외이기 때문입니다.
- 저장 중 `OSError`가 나면 안내 메시지만 출력하고 프로그램은 계속 실행합니다.

## 14. 개발 중 겪은 문제와 해결

| 문제 | 원인 | 해결 |
|---|---|---|
| 퀴즈를 추가했는데 선택지가 1개만 저장됨 | 선택지를 입력받는 반복문에서 첫 입력 직후 `break`해서 4개를 받기 전에 반복이 끝남 | 선택지 번호 `n`을 올리고 `n > 4`일 때만 `break`하도록 수정 |
| 메뉴 1~4번을 선택하면 프로그램이 끝남 | 각 분기에 반복문을 빠져나가는 `break`를 썼음 | 종료는 5번에서만 `break`하고, 나머지는 함수를 호출한 뒤 메뉴로 돌아오게 수정 |
| `AttributeError: 'Quiz' object has no attribute 'show_menu'` | `Quiz` 객체에 없는 메서드(`show_menu`)를 호출함. `show_menu`는 메뉴를 출력하는 일반 함수고, 퀴즈 출력은 `Quiz.show_quiz()` | 호출하려던 것에 맞춰 `show_quiz()`로 수정 |
| 점수가 0점일 때와 풀지 않았을 때를 구분할 수 없음 | `best_score` 초기값을 `0`으로 두면 같은 값이 됨 | 초기값을 `-1`("아직 없음")로 정하고, 점수 확인 시 `-1`이면 안내 메시지 출력 |
| 클래스로 옮긴 뒤 메서드 호출에서 에러 | 메서드가 `self`만 받는데 예전처럼 `quizzes`를 인자로 넘기거나, 속성을 `self.` 없이 사용 | 속성은 `self.quizzes`, `self.best_score`로 접근하고, 호출은 `self.메서드()`로 수정 |
| `gh repo create` 실행 시 `gh auth login`을 하라는 메시지 | WSL의 `gh`가 로그인되어 있지 않았음 | `gh auth login`으로 브라우저 인증 후 재실행 |

## 15. 학습 내용 정리

### Python 기초

| 개념 | 정리 | 이 프로젝트에서 |
|---|---|---|
| 변수 | 값에 이름을 붙여 저장하고 다시 쓰는 것 | `count`(맞힌 개수), `best_score`(최고 점수) |
| 자료형 | `int`(정수), `str`(문자열), `bool`(참/거짓), `list`(순서 있는 목록), `dict`(키-값 쌍) | 점수는 `int`, 문제는 `str`, 선택지는 `list`, JSON 저장 형태는 `dict` |
| 조건문 | `if/elif/else`로 조건에 따라 다른 동작 | 메뉴 번호에 따른 분기, 정답/오답 판정 |
| 반복문 | `for`는 순서가 있는 값을 하나씩 돌 때, `while`은 조건이 참인 동안 반복할 때 | `for q in self.quizzes`(퀴즈 순회), `while True`(올바른 입력이 들어올 때까지, 메뉴 반복) |
| 함수 | 매개변수로 값을 받고 `return`으로 결과를 돌려줌 | `read(prompt, low, high)`가 검증된 정수를 반환 |

### 클래스와 객체

- **클래스**는 데이터와 그 데이터를 다루는 기능을 한 묶음으로 만든 설계도입니다. 퀴즈마다 문제, 선택지, 정답을 따로 변수로 관리하면 복잡해지는데, `Quiz`로 묶으면 한 문제가 객체 하나가 됩니다.
- **`__init__`**은 객체가 만들어질 때 자동으로 실행되어 초기값(속성)을 저장합니다. **`self`**는 "지금 이 객체 자신"으로, `self.question`은 이 퀴즈의 문제를 뜻합니다. 메서드를 호출할 때는 `self`를 직접 쓰지 않고 파이썬이 객체를 자동으로 넘겨줍니다(`q.check(2)`).
- **속성**은 객체가 가진 데이터(`question`, `choices`, `answer`), **메서드**는 객체의 기능(`show_quiz`, `check`)입니다.
- `QuizGame`은 `quizzes`와 `best_score`를 속성으로 가져서, 메서드끼리 값을 주고받을 때 인자를 넘기거나 반환값을 다시 대입하지 않아도 됩니다.
- `from_dict`는 객체를 새로 만드는 함수라서 `@classmethod`로 두고, 클래스 자신(`cls`)으로 `cls(...)`를 호출합니다.

### 파일 입출력과 JSON

- 파일을 열고(`open`), 읽거나 쓰고, 닫는 것이 기본 과정입니다. `with open(...) as f:`를 쓰면 블록이 끝날 때 **자동으로 닫힙니다**.
- **JSON**은 데이터를 텍스트로 표현하는 형식으로, 파이썬의 `dict`, `list`, 문자열, 숫자와 모양이 비슷합니다. 프로그램을 종료하면 변수와 객체는 사라지지만 파일에 저장하면 다음 실행에서 다시 읽을 수 있어서 **데이터 영속성**에 사용합니다.
- `Quiz` 객체는 JSON으로 바로 저장할 수 없어서, `to_dict()`로 dict로 바꿔 저장하고 `from_dict()`로 다시 `Quiz`를 만듭니다.
- `encoding="utf-8"`과 `ensure_ascii=False`를 지정해 한글이 깨지지 않게 저장합니다.
- **`try/except`**는 오류가 나도 프로그램이 멈추지 않도록 처리합니다. 이 프로젝트에서는 숫자 변환 실패(`ValueError`), 파일 없음(`FileNotFoundError`), 손상된 JSON(`JSONDecodeError`), 입력 중단(`KeyboardInterrupt`, `EOFError`)을 처리합니다.

### Git 기초

- **Git**은 파일의 변경 이력을 관리하는 도구입니다. 이전 상태로 돌아가거나, 언제 무엇이 바뀌었는지 확인하고, 기능별로 작업을 나눌 수 있습니다.
- `init`(저장소 만들기) → `add`(커밋할 변경 선택) → `commit`(이력으로 저장) → `push`(GitHub에 올리기)가 기본 흐름이고, `pull`은 GitHub의 변경을 가져옵니다.
- **브랜치**는 작업 갈래입니다. `checkout -b`로 새 브랜치에서 기능을 만들고, 완성되면 `main`으로 돌아가 `merge`로 합칩니다. `main`을 안정적으로 유지하면서 새 기능을 실험할 수 있습니다.
- `clone`은 원격 저장소를 통째로 새 폴더에 복제하는 명령입니다.
